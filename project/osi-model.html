OSI Model

The Open Systems Interconnection (OSI) Model is a seven-layer conceptual framework used to describe how data is transmitted between devices on a computer network. Each layer performs a specific function, enabling different hardware and software systems to communicate effectively. The OSI Model helps network engineers design, troubleshoot, and understand network communication.

Layer 7 - Application

Provides network services directly to end-user applications such as web browsers, email, and file transfers.

Layer 6 - Presentation

Translates, encrypts, decrypts, and compresses data to ensure compatibility between systems.

Layer 5 - Session

Establishes, manages, and terminates communication sessions between network devices.

Layer 4 - Transport

Ensures reliable data delivery using error detection, flow control, and segmentation.

Layer 3 - Network

Determines the best route for data using logical addressing and routing protocols.

Layer 2 - Data Link

Transfers data between devices on the same network and detects transmission errors.

Layer 1 - Physical

Transmits raw bits through physical media such as cables, fibre optics, and wireless signals.
